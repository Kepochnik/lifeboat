# Changelog

## 3.0.2 — 2026-07-18

### Gameplay

- Rebuilt the game around a separate, testable rules engine.
- Fixed rowing and multi-card navigation rendering crashes.
- Fixed the missing end-game secrets container.
- Restored the base 42-card Provision deck and all six official character stats.
- Added deterministic fights, supporters, defender tie wins, wounds, unconsciousness and death.
- Added Oar, Compass, Flare Gun, Parasol, Medical Kit, Life Preserver and Bucket of Chum rules.
- Added 1/4/8 Jewel set scoring, character treasure affinities, Narcissist, Psychopath and ambivalent scoring.
- Added separate named, rowing and fighting thirst requirements.
- Added free Action-phase trading, Kid's hidden theft and corpse/lost-at-sea handling.

### Experience

- Replaced the single-file prototype with semantic HTML, modular JavaScript and a complete responsive visual system.
- Added pass-the-phone privacy gates, autosave/restore, undo and save import/export.
- Added Russian/English localization, tutorial, full quick rules, themes, text scaling, reduced motion, sound and haptics.
- Added keyboard controls, focus handling, screen-reader labels and accessible selection states.
- Added installable/offline PWA support and a Wake Lock while playing.

### Project health

- Removed the duplicate HTML build and obsolete prototype.
- Added README, legal notice, MIT license, automated tests and GitHub Actions verification.
