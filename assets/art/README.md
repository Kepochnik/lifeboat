# Lifeboat illustration assets

These original game illustrations were generated specifically for this
unofficial project with OpenAI's built-in image generation tool on 2026-07-18.
No input or commercial game artwork was used as a reference.

## Files

- `character-atlas.webp` — six original painted portraits in a 3 × 2 atlas:
  Lauren, Stephen, Captain, Mate, Frenchy, Kid.
- `lifeboat.webp` — an original transparent illustration of a wooden six-seat
  survival boat.
- `tabletop-v2.webp` — a seamless-feeling top-down teal felt and dark walnut
  tabletop surface designed to crop safely on phones and desktops.

The source generations were converted to optimized WebP files for the web.

## Art direction

Premium adult tabletop illustration, digital gouache with restrained engraved
linework, warm lantern highlights, cool ocean rim light, deep teal shadows,
parchment highlights, and distinct muted character colors. No text, logos,
trademarks, or copied character likenesses.

The tabletop was generated in the same built-in mode from a text-only prompt:
premium top-down adult nautical board-game surface, petrol-teal wool felt framed
by dark walnut, subtle salt patina, soft lamplight, no pieces or text.
