# Lifeboat — За бортом

Обновлённая локальная pass-and-play адаптация карточной игры для 4–6 человек. Один телефон передаётся по кругу; личные карты, любовь и ненависть показываются только своему игроку.

## Что реализовано

- полный цикл дня: раздача квартирмейстера, действия, навигация;
- гребля с выбором навигационных карт, пересадка, ограбление и драки с поддержкой сторон;
- свободная торговля во время фазы действий без расходования хода;
- падение за борт, спасательный круг, способность Француза и приманка для акул;
- отдельная жажда за имя, греблю и участие в драке;
- бессознательность при числе ран, равном силе, и смерть при превышении силы;
- финальный подсчёт выживания, любви, ненависти, сокровищ, нарциссизма и психопатии;
- базовая колода из 42 припасов: 16 вод, точный набор сокровищ, оружия и специальных карт;
- комплектный счёт самоцветов 1/4/8, одноразовая ракетница, бонус весла и компаса;
- спасательный круг другому персонажу и складывающиеся эффекты вёдер с приманкой;
- точные тайминги Малыша, зонтика, компаса и открытия оружия перед дракой;
- автосохранение, восстановление, отмена последнего шага, импорт/экспорт партии;
- тактильный мобильный стол из фетра и дерева, бумажные карты и крупные зоны касания;
- тихая процедурная мелодия с отдельным выключателем и паузой в фоне;
- русская и английская локализация, светлая/тёмная тема, масштаб текста и уменьшение анимации;
- адаптивный интерфейс, клавиатурная навигация, screen-reader подписи и офлайн-режим PWA.

## Запуск

Проект не требует сборщика или внешних зависимостей. ES-модули нужно открывать через локальный HTTP-сервер:

```bash
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Проверка

Требуется Node.js 20 или новее:

```bash
npm run verify
```

## Структура

- `src/data.js` — колоды и параметры персонажей;
- `src/engine.js` — чистая модель правил;
- `src/i18n.js` — русский и английский тексты;
- `src/app.js` — экраны, приватная передача хода и сохранения;
- `styles.css` — визуальная система и адаптивность;
- `tests/engine.test.js` — регрессионные тесты ключевых правил.

## Ограничения

Это локальная игра на одном устройстве, а не сетевой мультиплеер. Реализована базовая версия на шесть персонажей без дополнений Cannibalism, Weather Deck и Liquid Courage. Подробности о правах и публикации находятся в [NOTICE.md](NOTICE.md).
